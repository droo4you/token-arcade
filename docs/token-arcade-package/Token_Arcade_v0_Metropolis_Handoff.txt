1. PRODUCT THESIS
Token Arcade is a browser arcade for internet communities.
A visitor should be able to land on the site and immediately understand:
There are fun games here.
I can play them immediately.
If I create an account, my arcade identity persists.
Some games have competitive modes.
Some games have their own experimental economies.
Some games are connected to existing internet communities.
Those communities can host competitions and reward their players.
Crypto infrastructure should enable the product.
Crypto infrastructure should not dominate the interface.
The user should experience:
game -> fun -> identity -> competition -> community -> rewards
rather than:
wallet -> token -> contract -> transaction -> game

12. SCORE VERIFICATION
Do NOT trust arbitrary scores supplied by the browser.
V0 uses a game-specific Score V erifier boundary.
The browser/game produces a structured run result, but Token Arcade decides
how that result is accepted for Ranked/Raid use.
Supported verifier patterns include:
A. Session / telemetry validation
Authenticated run session plus sanity checks, timing/plausibility bounds, replay
protection, and game-specific telemetry validation.
B. Server-authoritative verification
A trusted server/judge owns hidden or authoritative state and determines the
accepted result.
C. Deterministic replay
The game supplies suﬀicient inputs/seed/version data for the verifier to replay
the simulation and recompute the result.
Deterministic replay is desirable where practical, but it is not a universal
admission requirement for every Raid-ready Cartridge.
Requirements:
• every Ranked/Raid-capable game declares its verifier type
• the client is never the final authority
• run IDs/session tokens are replay-protected
• verification is pinned to game/version/rules
• invalid/tampered results are rejected
• the strongest practical verifier should be used without rewriting a working
game solely to satisfy replay for Metropolis
Contracts/backend accept only authenticated/verified settlement data.
Do not attempt to solve perfect anti-cheat for Metropolis.
Build a credible verification boundary that can harden later.
